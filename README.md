# Информационная система для автосалона (Backend)

Полнофункциональная микросервисная backend-система для мультибрендового автосалона. Проект реализует полный цикл клиентских заказов, конфигуратор автомобилей, управление складскими запасами, ролевую авторизацию и асинхронно-синхронное межсервисное взаимодействие.

---

## Архитектура системы

Система состоит из двух независимых микросервисов, разворачиваемых в отдельных Docker-контейнерах с собственными базами данных:

* **`OrderService`** — сервис работы с клиентами, заказами, заявками на тест-драйв, жизненным циклом заказов и конфигуратором автомобилей.
* **`StorageService`** — сервис складского учёта, управления каталогом автомобилей и запчастей и процессом сборки.

---

## Технологический стек

* **Язык и фреймворк:** Java 25, Spring Boot, Gradle
* **Базы данных и миграции:** PostgreSQL, Spring Data JPA, Liquibase
* **Безопасность:** Spring Security, Keycloak (JWT, система ролей)
* **Межсервисное взаимодействие:**
  * **Внешнее:** REST API (JSON)
  * **Асинхронное:** Kafka с реализацией **Outbox Pattern** (гарантия атомарности и идемпотентности)
  * **Синхронное:** gRPC
* **Документация API:** Swagger UI
* **Тестирование и инфраструктура:** Testcontainers, Docker

---

## Модель безопасности (Keycloak и Spring Security)

| Роль | Права и области доступа |
| :--- | :--- |
| **`USER`** | Создание заказов, просмотр и отмена **только своих** заказов, просмотр каталога авто. |
| **`MANAGER`** | Просмотр всех заказов, управление статусами заказов, управление списком авто для тест-драйва. |
| **`WAREHOUSE_ADMIN`** | Полный доступ к `StorageService`, управление остатками и `Заказами на сборку`. |
| **`ADMIN`** | Полный неограниченный доступ ко всем REST-эндпоинтам обоих сервисов. |

## Взаимодействие с системой (REST API)

### OrderService

| Эндпойнт | Операции по назначению |
| :--- | :--- |
| **`/api/v1/cars`** | Получение информации об автомобилях в наличии |
| **`/api/orders`** | Операции с заказами |
| **`/api/test-drive-requests`** | Операции с заявками на тест-драйв |

### StorageService

| Эндпойнт | Операции по назначению |
| :--- | :--- |
| **`/api/assembly`** | Внутренние операции с заказами на сборку |
| **`/api/cars`** | Операции с автомобилями |
| **`/api/car-details`** | Операции с моделями автомобилей и запчастями |
| **`/api/inventory`** | Инвентарные операции |
